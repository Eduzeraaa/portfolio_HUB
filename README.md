# PortfolioHUB + IA GEMINI 🚀

Plataforma centralizada para exibição, gerenciamento de portfólios digitais e projetos de Engenharia de Software. Este projeto foi implantado como o Desafio Final de Bootcamp, integrando controle de versão via GitHub e automação de dados.

---

## 📋 Seções do Projeto (Conformidade com o Desafio)

### 1. Planejamento da Implantação
* **Trilha de Implantação:** Planejada e validada com o apoio da IA Google GEMINI para garantir a estrutura correta e conformidade com os requisitos da banca.
* **Tecnologias:** Desenvolvimento utilizando arquitetura limpa com HTML5, CSS3 Vanilla (Vibecoding) e JavaScript assíncrono (Consumo de APIs).

### 2. Configuração Inicial e Integração com GitHub
* **Ambiente Dedicado:** Criação e configuração de um repositório Git isolado na máquina local e sincronizado via terminal com o GitHub.
* **Armazenamento de Projetos:** O portfólio consome dinamicamente a API pública do GitHub para renderizar e listar os projetos reais do desenvolvedor em tempo real.

### 3. Gestão de Usuários e Segurança
* **Políticas de Acesso:** Controle de acessos e versionamento gerenciado pelas permissões nativas de colaboradores do GitHub.
* **Segurança da Informação (Client-Side Security):** Alinhado com as melhores práticas de segurança validadas pelo GEMINI, o projeto elimina riscos de vazamento de chaves privadas ao utilizar exclusivamente chamadas assíncronas a endpoints públicos da API do GitHub, sem exposição de Personal Access Tokens (PAT) no código do cliente.

### 4. Compartilhamento e Controle de Acesso
* **Controle de Versão:** Repositório configurado para controle de branches, histórico de commits padronizado (Conventional Commits) e compartilhamento seguro de código.

### 5. Finalização e Testes
* **Ambiente de Produção:** Estrutura otimizada e testada para deploy contínuo em servidores de hospedagem estática.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5** - Estruturação semântica da página.
* **CSS3** - Estilização moderna e responsiva (Layout Dark Theme).
* **JavaScript (ES6+)** - Manipulação do DOM, criação do carrossel e consumo da API do GitHub.
* **Git & GitHub** - Versionamento e controle de acesso.
* **Google GEMINI IA** - Ferramenta de apoio, mentoria e guia durante o processo de implantação.
